# De Paul Counselling Centre Website

A responsive and user-friendly website developed for **De Paul Counselling Centre** to provide information about counselling services, programs, and mental health support.

The website is designed to make it easy for visitors to learn about the centre, explore available services, and contact the organisation.

## 🌐 Live Website

**De Paul Counselling Centre**
[www.depaulcounselling.com](http://www.depaulcounselling.com)

## 📌 About the Project

This project was developed as a professional website for De Paul Counselling Centre. It focuses on providing a clean, accessible, and responsive interface where users can easily find information about counselling services and the organisation.

The website is optimized to work across desktop, tablet, and mobile devices.

## ✨ Features

* Responsive website design
* User-friendly navigation
* Information about counselling services
* About Us section
* Programs and services information
* Contact information
* Mobile-friendly layout
* Clean and professional user interface
* SEO-friendly page structure
* Cross-browser compatibility

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Bootstrap
* Responsive Web Design

## 🎯 Project Objectives

The main objectives of this project are:

* Provide information about De Paul Counselling Centre online
* Help users understand the counselling services offered
* Make important information easy to access
* Provide a professional online presence for the organisation
* Ensure the website works smoothly across different screen sizes

## 📱 Responsive Design

The website is designed using responsive web development techniques so that the layout automatically adapts to:

* Desktop computers
* Laptops
* Tablets
* Mobile phones

## 🚀 Running the Project

Clone the repository:

```bash
git clone <repository-url>
```

Open the project folder:

```bash
cd Depaul
```

Then open `index.html` in your browser.
